## What it is

A GraphQL API over the Centrifuge parachain, built with SubQuery — pools,
tranches, investments, epochs, rewards as indexed from Substrate events and
extrinsics. Built and largely maintained by **EMBRIO.tech**, who also built
`api-v3`.

Still relevant for querying historical V2 pool performance; the docs keep a
page for exactly this at `developer/legacy/querying-v2-data/`.
